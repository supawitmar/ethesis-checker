# แท็บ "ผิดซ้ำ" ในชีทบันทึกการตรวจ (สูตรล้วน ไม่มีสคริปต์)

เพิ่ม 2 ต.ค. 2569 ตามคำสั่งเจ้าหน้าที่ ("การผิดซ้ำ ... คำนวณจากข้อมูลที่บันทึกอยู่แล้วได้")
คำนวณจากแท็บ **จุดผิด** ซึ่งสคริปต์แดชบอร์ดของชีทสร้างไว้ (1 แถว = 1 ข้อผิด) ไม่ต้องให้ระบบตรวจ
เก็บข้อมูลเพิ่ม และไม่แตะแท็บเดิมเลย

- ตำแหน่ง: แท็บลำดับที่ 5 (ต่อจาก "จุดผิด") — สคริปต์ที่ติดชีท (`tools/sheet_webhook.gs`)
  หยิบ "แท็บซ้ายสุด" (`getSheets()[0]`) จึงไม่กระทบ
- ไม่ใส่ในแท็บ "แดชบอร์ด" เพราะแท็บนั้นถูกสคริปต์เขียนทับทุกชั่วโมง (สคริปต์แดชบอร์ดไม่อยู่ใน repo นี้)
- ลบทิ้งได้ทุกเมื่อ (คลิกขวาที่แท็บ > Delete) ไม่มีอะไรอื่นผูกกับมัน

## นิยาม

- **รอบ** = (รหัสนักศึกษา, วันเข้าคิว, วันที่ตรวจ) — วันเข้าคิวอย่างเดียวไม่พอ นักศึกษาคนเดียวส่งใหม่
  ในวันเข้าคิวเดิมแต่ตรวจคนละวันได้ (เจอจริงจากข้อมูล ก.ย. 2569)
- **ผิดซ้ำ** = ประเด็นเดียวกัน ที่เคยถูกบอกนักศึกษาคนเดิมในรอบที่ "ตรวจก่อนหน้า" แล้วปรากฏอีกในรอบนี้
  นับครั้งละ 1 ต่อ (รอบ, ประเด็น) ไม่นับซ้ำตามจำนวนจุดในรอบเดียวกัน (ชื่อบทผิด 3 บท = 1 ประเด็น)
- ไม่รวมรอบที่ผ่าน (เสร็จสิ้น/แจ้งค่าปรับ) เพราะไม่มีข้อผิดให้นับ และแท็บ จุดผิด เริ่มตั้งแต่ ส.ค. 2569

## เค้าโครง

| ช่วง | ที่นี่คืออะไร |
|---|---|
| `A1:D11` | ภาพรวม 7 ตัวเลข (นักศึกษา/รอบ/ผิดซ้ำ ฯลฯ) |
| `A14:E…` | ตารางประเด็น เรียงจากผิดซ้ำมากไปน้อย (คอลัมน์ E = % ผิดซ้ำ) |
| `G14:K54` | รายการผิดซ้ำล่าสุด 40 รายการ (รหัส วันที่ ประเด็น เคยถูกบอกมาแล้วกี่รอบ) |
| `M:Y` | ตัวช่วยคำนวณ (จัดกลุ่มและพับไว้ กดเครื่องหมาย + ด้านบนเพื่อเปิด) ห้ามลบ |

## สูตรตัวช่วย (แถว 2 ของ `M:Y`, อ้างแถว 2–1500 ของ จุดผิด)

```text
M  id            =ARRAYFORMULA(IF('จุดผิด'!B2:B1500="","",'จุดผิด'!B2:B1500&""))
N  ประเด็น        =ARRAYFORMULA(IF(M2:M1500="","",'จุดผิด'!G2:G1500))
O  วันที่ตรวจ      =ARRAYFORMULA(IF(M2:M1500="","",IFERROR(DATEVALUE('จุดผิด'!E2:E1500),'จุดผิด'!E2:E1500)))
P  วันเข้าคิว      =ARRAYFORMULA(IF(M2:M1500="","",IFERROR(DATEVALUE('จุดผิด'!D2:D1500),'จุดผิด'!D2:D1500)))
Q  รอบ            =ARRAYFORMULA(IF(M2:M1500="","",M2:M1500&"|"&P2:P1500&"|"&O2:O1500))
R  รอบ×ประเด็น     =ARRAYFORMULA(IF(M2:M1500="","",Q2:Q1500&"|"&N2:N1500))
S  ครั้งแรกของ R   =ARRAYFORMULA(IF(M2:M1500="",0,--(MATCH(R2:R1500,R2:R1500,0)=ROW(R2:R1500)-1)))
T  รอบก่อนที่เคยบอก =ARRAYFORMULA(IF(M2:M1500="",0,COUNTIFS(M2:M1500,M2:M1500,N2:N1500,N2:N1500,O2:O1500,"<"&O2:O1500,S2:S1500,1)))
U  ผิดซ้ำ          =ARRAYFORMULA(IF(M2:M1500="",0,(S2:S1500=1)*(T2:T1500>0)))
V  รหัส×ประเด็นที่ซ้ำ =ARRAYFORMULA(IF(U2:U1500=1,M2:M1500&"|"&N2:N1500,""))
W  ครั้งแรกของ V   =ARRAYFORMULA(IF(V2:V1500="",0,--(MATCH(V2:V1500,V2:V1500,0)=ROW(V2:V1500)-1)))
X  ครั้งแรกของรอบ   =ARRAYFORMULA(IF(M2:M1500="",0,--(MATCH(Q2:Q1500,Q2:Q1500,0)=ROW(Q2:Q1500)-1)))
Y  รอบของรหัส      =ARRAYFORMULA(IF(M2:M1500="",0,COUNTIFS(M2:M1500,M2:M1500,X2:X1500,1)))
```

ตารางประเด็น (`A14`) และรายการล่าสุด (`G15`)

```text
A14  =IFERROR(QUERY({N2:N1500,S2:S1500,U2:U1500,W2:W1500},"select Col1, sum(Col2), sum(Col3), sum(Col4) where Col1 <> '' group by Col1 order by sum(Col3) desc, sum(Col2) desc label Col1 'ประเด็น', sum(Col2) 'ผิดทั้งหมด (รอบ×ประเด็น)', sum(Col3) 'ผิดซ้ำ', sum(Col4) 'จำนวนคนที่ผิดซ้ำ'",0),"")
E15  =ARRAYFORMULA(IF(A15:A="","",IF(B15:B=0,"",C15:C/B15:B)))
G15  =IFERROR(ARRAY_CONSTRAIN(SORT(FILTER({M2:M1500,P2:P1500,O2:O1500,N2:N1500,T2:T1500},U2:U1500=1),3,FALSE),40,5),"")
```

ภาพรวม (`B5:B11`): `COUNTUNIQUE(FILTER(M…))` นักศึกษา · `COUNTUNIQUE(FILTER(Q…))` รอบ ·
นักศึกษาที่ถูกส่งกลับ ≥ 2 รอบ = `FILTER(M, Y>=2)` · รอบ/นักศึกษาที่มีประเด็นซ้ำ = `FILTER(Q|M, U=1)` ·
`SUM(U)` และ `SUM(S)` สำหรับสัดส่วนของประเด็นที่ผิดซ้ำ

## ข้อจำกัดที่ต้องรู้

- **รองรับ จุดผิด ถึงแถว 1500** (ตอนสร้างมี 780) เกินแล้วต้องแก้เลข `1500` ในทุกสูตรและเพิ่มจำนวนแถว
  ของแท็บให้พอ (สูตรอาร์เรย์ขยายเกินแถวสุดท้ายของแท็บไม่ได้ จะขึ้น #REF!) ทุกวันนี้ราว 250-550 แถวต่อเดือน
- ถ้าสคริปต์แดชบอร์ด **ลบแล้วสร้างแท็บ จุดผิด ใหม่** (แทนที่จะเคลียร์ค่าในแท็บเดิม) สูตรทั้งหมดจะขึ้น #REF!
  แก้โดยครอบ `'จุดผิด'!B2:B1500` เป็น `INDIRECT("'จุดผิด'!B2:B1500")` (ตอนสร้างยังไม่ได้ทำ เพราะยังไม่รู้ว่า
  สคริปต์ทำแบบไหน — ถ้าเจอ #REF! ให้ทำตามนี้)
- ตัวเลขรายประเด็นมาจากข้อมูลช่วงสั้น ใช้ดูแนวโน้ม ไม่ใช่ข้อสรุป

## ตรวจแล้วเมื่อสร้าง (2 ต.ค. 2569)

เทียบกับการคำนวณแยกด้วย Python จากข้อมูลชุดเดียวกัน (กุญแจรอบเดียวกัน): รอบที่ส่งกลับ 136 ตรงกัน ·
นักศึกษาที่ถูกส่งกลับ ≥ 2 รอบ 32 (Python 31 ไม่นับรอบที่ไม่ใช่ส่งกลับ 1 รอบ) · ผิดซ้ำของชื่อบท 12 /
เลขหน้า 5 / ชื่อเรื่อง 4 / วันที่สอบผ่าน 3 (Python นับเฉพาะรอบติดกัน ได้ 11 / 5 / 4 / 3 ต่างกันเพราะสูตรนี้
นับรอบก่อนหน้าทุกรอบ ไม่ใช่เฉพาะรอบเดียวที่อยู่ติดกัน) · เคสที่รู้คำตอบ (รหัสที่ส่งซ้ำด้วยข้อผิดชุดเดิมทุกข้อ)
ถูกนับเป็นผิดซ้ำครบทุกประเด็น และรอบแรกของรหัสเดียวกันไม่ถูกนับ

## อ่านผลอย่างระวัง

- **กติกาของระบบตรวจเปลี่ยนตลอดช่วงข้อมูลนี้** ประเด็นที่ "ใหม่" ในรอบที่สองจึงอาจมาจากกติกาที่เพิ่ม
  ไม่ใช่นักศึกษาทำผิดใหม่ เช่น 9 ก.ย. 2569 รายชื่อกรรมการไม่ครบเปลี่ยนจากส้มเป็นแดง (commit `b128326`) —
  ก่อนวันนั้นข้อนี้ไม่ถูกส่งให้นักศึกษา (ส้มส่งเมื่อเจ้าหน้าที่กดไม่ผ่านเท่านั้น) ผิดซ้ำจึงเชื่อถือได้กว่าผิดใหม่
- รอบต้นเดือน ส.ค. 2569 เจ้าหน้าที่พิมพ์รายละเอียดเอง (ที่มา = "พิมพ์เอง") ซึ่งมักสั้นกว่าที่ระบบตรวจเจอ
  รอบถัดไปที่ใช้ข้อความจากระบบจึงดูเหมือนมีข้อใหม่เยอะ
- ข้อส้ม/เหลืองที่เจ้าหน้าที่กด "ผ่าน" ไม่ถูกบันทึกในชีท จึงไม่อยู่ในตัวเลขนี้
