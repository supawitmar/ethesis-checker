# กฎที่ระบบตรวจ แยกตามหน้าของเล่ม

อ้างอิงจาก `code/checker.py` (`run_check`) — ถ้าโค้ดกับเอกสารนี้ไม่ตรงกัน **โค้ดคือความจริง**
ให้แก้เอกสารนี้ตาม

## ก่อนตรวจอย่างอื่น: ภาษาของเล่ม

| ตรวจอะไร | รหัสกฎ | ผิด = |
|---|---|---|
| ภาษาของเล่มตรงกับหลักสูตรที่อนุมัติ (ปก / หน้าลงนาม / หัวบท) | `FORM.BOOK_LANGUAGE` | แดง |

ไม่ตรงทั้งเล่ม = **หยุดตรวจส่วนอื่นทั้งหมด** เหลือจุดผิดข้อเดียว และข้อนี้อยู่บนสุดของรายงาน
ถ้าสัญญาณขัดกันเอง (เช่น ปกอังกฤษ แต่หัวบทเป็น "บทที่ 1") ฟ้องแดงแต่ยังตรวจส่วนอื่นต่อ

## เลขหน้าส่วนนำ (ทุกหน้า ตั้งแต่หน้าลงนามถึงก่อนบทที่ 1)

| หลักสูตร | ต้องใช้ |
|---|---|
| `thai` | พยัญชนะไทย `ก ข ค ง จ …` |
| `international`, `thai_english` | เลขโรมัน `i ii iii iv …` |

- ชนิดผิดจากภาษาเล่ม (รวมอารบิก) = **แดง**
- ซ้ำ / ข้าม = **แดง**
- ระบบอ่านเลขหน้าไม่ได้ = **ส้ม** และไม่ฟ้อง "ข้าม" คร่อมหน้านั้น
- หน้าลงนามที่ข้อ "หน้าลงนาม 1/2" (`PAGE.SIGNATURE_LABEL` ส้ม) ฟ้องแล้ว ไม่นับซ้ำในข้อ
  "ไม่ได้พิมพ์เลขหน้าไว้" / "เลขหน้าผิดชนิด" ของส่วนนำ (ก.ย. 2569)
- หาหน้าบทที่ 1 ไม่เจอ = ข้ามการตรวจ (ไม่เดาขอบเขตส่วนนำ)

**กฎรูปแบบ 3 ข้อของรายชื่อกรรมการเป็นกฎ template ล้วน — ตรวจแม้ไม่มีข้อมูล eThesis**
มีเฉพาะการเทียบชื่อ/ลำดับที่ต้องใช้ข้อมูลอนุมัติ

**ชื่อนักศึกษาที่ "ไม่ตรง" ต้องรายงานข้อความในช่องของชื่อ ไม่ใช่บรรทัดที่คล้ายที่สุด** —
ช่องของชื่อชี้จาก template: หน้าปกคือบรรทัดก่อน `A THESIS SUBMITTED...` หน้าลงนามคือ
บรรทัดเหนือ `Candidate`/`ผู้วิจัย` หน้าบทคัดย่อคือข้อความหน้ารหัสนักศึกษา
ดู `RULES_AND_SOURCES.md` หัวข้อ "ช่องของชื่อนักศึกษาชี้จากโครงสร้างของหน้า"

## เนื้อหา

| ตรวจอะไร | รหัสกฎ | ผิด = |
|---|---|---|
| จำนวนบท (รูปแบบ 1 = 6 บท, รูปแบบ 2 = 2–3 บท) | `BODY.OPTION1/2` | แดง |
| รูปแบบที่เล่มจัดบท (ดูจากชื่อบทที่ 1: บทสรุป/SUMMARY = รูปแบบ 2) ตรงกับที่เลือก | `FORM.APPROVED_MATCH` | แดง (strict) / ส้ม (free) |
| ชื่อบทตรงประกาศ | `BODY.OPTION1/2` | แดง (แบบคู่มือ = ส้ม) |
| เลขหน้าอารบิกเริ่มที่ 1 และต่อเนื่อง | `PAGE.NUMBERING` | แดง |

| หน้าที่ดึงข้อความไม่ได้ | `PAGE.BLANK` / `UNCERTAIN.REVIEW` | เหลือง / ส้ม |

**ขอบเขตชื่อบทตามรูปแบบ** (`CANONICAL_ENFORCED_COUNT`): รูปแบบ 1 บังคับชื่อบท 1–6,
รูปแบบ 2 บังคับเฉพาะบท 1–2 (บทที่ 3 มีได้แต่ไม่บังคับชื่อ)

ชื่อบทต้อง **ครอสเช็ค 3 ทาง** — สารบัญ↔ประกาศ, เนื้อหา↔ประกาศ, สารบัญ↔เนื้อหา
รายงานแยกกัน ไม่กลบกัน เพื่อให้รู้ว่าฝั่งไหนผิด
